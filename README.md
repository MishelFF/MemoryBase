# Описание 
## Основные особенности
Демонстрационный проект на QT QML. Создание и использование базы медиафайлов с внешних носителей.
Приложение мультиплатформенное, собирается под Windows, Linux и Android.
Предусмотренно 2 режима взаимодействия клиентской и серверной части: REST API или прямое подключение к SQL серверу.
Выбор режима работы реаклизован с помошью полиморфизма, абстрактный базовый класс источника данных и два наследника, реализующих реальную логику подключения.  
База данных на сервере Postgre, можно легко перенести на другой популярный SQL сервер.
В проекте используются различные виды потоков и механизмы их взаимодействия. Логика работы с базой вынесена в отдельный обший поток, для паралельной загрузки и обработки новых файлов используется пул коротких конкурирующих процессов.
## Распознавание и поиск лиц
Проект развивается в сторону расширения возможностей распознавания и поиска лиц с использованием нейросетей.
Распознавание лиц построено на связке из трёх нейросетевых моделей:

1. **Детектор лиц** (HOG + линейный классификатор) находит на фото прямоугольные области, где есть лицо.
2. **Модель ключевых точек** по найденной области определяет опорные точки лица (контур, глаза, нос, рот). Они нужны, чтобы выровнять лицо (повернуть и отцентровать).
3. **Сеть распознавания**, (архитектура на основе ResNet) — принимает выровненное лицо и выдаёт дескриптор (вектор из 128 чисел). 

Сами дескрипторы хранятся в базе (PostgreSQL с расширением `pgvector`). Использование возможностей PostgreSQL позволяет искать похожие лица прямо через SQL-запрос с оператором евклидова расстояния, без перебора в коде приложения.

Два разных способа связать лицо на фото с человеком из справочника:

- **По явной привязке** — лицо уже сопоставлено вручную через панель сопоставления.
- **По расстоянию между дескрипторамиа** — сравнение с эталонным вектором человека с настраиваемым порогом; находит и те лица, которые ещё никто не подтверждал вручную.

## Демонстрация системы лицензирования
Отдельно в проекте реализована система лицензирования с использованием цифровой подписи на оснлове современного ассиметричного шифрования Ed25519.При активации программа отправляет на сервер лицензионный ключ и идентификатор компьютера. Сервер проверяет лицензию в базе данных, формирует лицензионный файл в формате JSON и подписывает его с помощью алгоритма Ed25519 (libsodium). Подписанная лицензия возвращается программе и сохраняется локально. Закрытый ключ используется только на сервере и никогда не передается. Информация о лицензиях и активациях хранится в базе данных, ключевые файлы формируются в процессе активации.

## Структура проекта

- `client/` — Qt Quick приложение (C++ / QML)
- `server/` — PHP API для загрузки данных

## Требования
**Клиент:**
- Qt 6.x (Quick, QuickControls2, Sql, Network)
- CMake 3.21+## Настройка сервера
**Сервер:**
- Docker + Docker Compose 
- или:  PostgreSQL и PHP 8.x + веб-сервер с поддержкой PDO pgsql (ручная установка)

##  Быстрый запуск в Docker
Перейдите в директорию server
```bash
cd server
```
cp .env.example .envСоздайте локальный файл конфигурации .env из шаблона example .env:
```bash
cp .env.example .env
```
* `DB_PASSWORD` — придумайте пароль для базы данных.
* `API_PORT` — укажите порт, на котором API будет доступно на вашем компьютере (например, `6780`).
* `PHOTOS_PATH` — укажите абсолютный путь к папке с фотографиями на вашем компьютере.
Запустите сборку и старт всех сервисов в фоновом режиме:
```bash
docker compose up -d --build
```
##  Ручная настройка
1. Создайте базу данных при помощи `server/db-init/photobase.sql`
2. Скопируйте `server/php/` на веб-сервер с поддержкой PHP 8.x и модуля `pdo_pgsql`.
3. Настройте в `server/config.php` параметры подключения к серверу или настройте переменные окружения веб сервера


## Настройки приложения
