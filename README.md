Демонстрационный проект на QT QML. Создание и использование базы медиафайлов с внешних носителей.
Приложение мультиплатформенное, собирается под Windows, Linux и Android.
Предусмотренно 2 режима взаимодействия клиентской и серверной части: REST API или прямое подключение к SQL серверу.
Выбор режима работы реаклизован с помошью полиморфизма, абстрактный базовый класс источника данных и два наследника, реализующих реальную логику подключения.  
База данных на сервере Postgre, можно легко перенести на другой популярный SQL сервер.
В проекте используются различные виды потоков и механизмы их взаимодействия. Логика работы с базой вынесена в отдельный обший поток, для паралельной загрузки и обработки новых файлов используется пул коротких конкурирующих процессов. 

## Структура проекта

- `client/` — Qt Quick приложение (C++ / QML)
- `server/` — PHP API для загрузки данных

## Требования
**Клиент:**
- Qt 6.x (Quick, QuickControls2, Sql, Network)
- CMake 3.21+## Настройка сервера
**Сервер:**
- Docker + Docker Compose 
- или:  PostgreSQL и PHP 8.x + веб-сервер с поддержкой PDO pgsql (ручная установка)

###  Быстрый запуск в Docker
Перейдите в директорию server
```bash
cd server
```
cp .env.example .envСоздайте локальный файл конфигурации .env из шаблона example .env:
```bash
cp .env.example .env
```
* `DB_PASSWORD` — придумайте пароль для базы данных.
* `API_PORT` — укажите порт, на котором API будет доступно на вашем компьютере (например, `6780`).
* `PHOTOS_PATH` — укажите абсолютный путь к папке с фотографиями на вашем компьютере.
Запустите сборку и старт всех сервисов в фоновом режиме:
```bash
docker compose up -d --build
```
###  Ручная настройка
1. Создайте базу данных при помощи `server/db-init/photobase.sql`
2. Скопируйте `server/php/` на веб-сервер с поддержкой PHP 8.x и модуля `pdo_pgsql`.
3. Настройте в `server/config.php` параметры подключения к серверу или настройте переменные окружения веб сервера


## Настройки приложения
